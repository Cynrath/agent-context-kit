# Public Benchmark Evidence — Offline, Deterministic, No Telemetry

**Methodology (maintainer operation, not product runtime):**
- Pinned exact SHAs from `benchmarks/public-repos.json` (20 repos across 5 ecosystems, fetched via `git ls-remote HEAD` on 2026-08-27, see `public-repos.json` for full list)
- Allowed operations: `git clone --depth 1` (or `git fetch <sha>`), read files, run ACKit's static/offline analysis (`scanRepository`, `buildInstructionGraph`, `buildContextPack`, `scoreRepository`, `validateSkills`)
- **Forbidden in third-party repos:** `npm/pnpm/yarn install`, `pip install`, `dotnet restore/build/test`, `cargo build/test`, `go test`, repository scripts/hooks, skills execution, arbitrary binaries, `curl`/`wget` beyond clone
- No network during analysis: product code never fetches; benchmark harness uses deny-egress patch (see `tests/security/offline-runtime.test.ts`) to assert zero egress
- No raw secret findings published — only aggregate counts (redacted at construction, `[REDACTED]` in all reporters)
- Deterministic: same repo+SHA+config → byte-identical findings/fingerprints; `benchmarks/run.mjs` median-of-3 for perf, `public-evidence.json` sorted

**Run command (maintainer):**
```bash
node ./benchmarks/run-public.mjs   # clones to /tmp/ackit-public-bench-*, runs offline analysis, writes benchmarks/public-evidence.json
```

**Benchmark perf (existing `benchmarks/run.mjs`):**
- 7 deterministic fixtures (small/medium/large/monorepo/instruction-heavy/skill-heavy/binary-heavy)
- 8 metrics: `coldScanMs`, `warmScanMs`, `incrementalMs`, `peakRssMb`, `filesPerSec`, `packMs`, `graphMs`, `cacheHitRatio`
- Median-of-3, thresholds `1.5×` vs `benchmarks/baselines/*.json`, PR advisory vs scheduled

**Safety:**
- No `npm install` etc. in third-party repos — verified by `grep -R "npm install" benchmarks/run-public.mjs` → 0 (only `git clone`)
- No raw secrets — `grep` for `AKIA|ghp_` in `public-evidence.md` → 0
- Offline guarantee: `offline-runtime.test.ts` harness would fail if benchmark tried to fetch

**Reproducibility:**
```bash
git clone https://github.com/Cynrath/agent-context-kit
cd agent-context-kit
pnpm install --frozen-lockfile && pnpm build
node ./benchmarks/run-public.mjs
cat benchmarks/public-evidence.json | jq .repos[0]
```

This evidence is **safe methodology + aggregate data** published in canonical docs (`docs/benchmarks/public-evidence.md`) and will be mirrored to hosted docs `https://cynrath.github.io/agent-context-kit/benchmarks/` via `sync-ackit-docs.mjs` (TASK-0031). It makes no marketing claims about being "fastest" — only deterministic, offline, and reproducible.
