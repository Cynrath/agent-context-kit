# ACKit documentation

ACKit is an offline-first TypeScript and Node.js toolkit for coding-agent repository readiness. It validates agent instructions, supports policy-aware workflows, optimizes context and records verification evidence.

## Install

Requires Node.js 22 or newer.

```powershell
npm install --global @cynrath/agent-context-kit
ackit --version
```

## First checks

```powershell
ackit readiness
ackit doctor
ackit scan --ci
```

Read the [getting started guide](/guides/getting-started), [CLI reference](/reference/cli), [configuration reference](/reference/config) and [evidence verification concepts](/concepts/evidence-verification).

For [Context7 indexing, Docs7 hosting and library owner verification](/guides/context7-docs7), follow the maintained integration guide.
