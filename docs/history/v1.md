# History — v1 (.NET line)

AgentContextKit v1 was a .NET/NuGet CLI (`AgentContextKit`, final release
`1.0.0-rc.1`). The published NuGet package, tag, GitHub release, and assets
are **immutable** historical artifacts and are not touched by any branch.

The vNext rebuild (this branch) replaces the C# runtime with a TypeScript +
Node.js implementation under a new version line (`0.1.0`+, scoped npm name)
and a fresh changelog. v1 documentation was removed from the final tree in
TASK-0287; the full historical corpus remains available in git history
(branch `master` and prior commits of `rebuild/ackit-vnext`) and summarized
in `docs/rebuild/VNEXT_TRACEABILITY.md` §"Old v1 task classification".

Concepts carried forward (as requirements, not code): docs-first/task-first
workflow discipline, exit-code standardization lessons, report UX lessons,
and the release-hygiene evidence culture.
