# ACKit Optimize synthetic demo

This is a deliberately small, public-safe repository fixture for demonstrating the post-`1.0.0-rc.1` ACKit Optimize source workflow. It contains no real credentials, private paths, customer data, or copyrighted project content.

The instruction surfaces intentionally contain:

- a root and nested `AGENTS.md` scope;
- exact and conservative near-duplicate verification rules;
- an unsafe deployment conflict that requires human review;
- a valid subtree-specific npm-to-pnpm override;
- vague and objectively unverifiable wording;
- one deterministically stale repository-relative reference; and
- mandatory security, verification, deployment, documentation, and release constraints.

Run the commands from the main AgentContextKit repository root. Generated reports belong under ignored `.ackit/` output and must not be committed.
