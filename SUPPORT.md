# Support

For questions, ideas, and community showcases, use [GitHub Discussions](https://github.com/Cynrath/agent-context-kit/discussions):

- **Q&A** — support questions
- **Ideas** — feature/product proposals
- **Show and tell** — integrations, rule packs, workflows
- **General** — open community conversation
- **Announcements** — maintainer releases/news (maintainer only)

Security reports stay under `SECURITY.md` — never Discussions.

For bugs and feature requests, use the [issue templates](.github/ISSUE_TEMPLATE/).

- Documentation: `docs/guides/` and `README.md`
- Discussions: https://github.com/Cynrath/agent-context-kit/discussions
- Sponsors: https://github.com/sponsors/Cynrath (active, see `.github/FUNDING.yml`)
